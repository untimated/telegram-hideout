# Prototype newspaper photos

These Wikimedia Commons photos illustrate the three handpicked Reader's Digest
subjects. They are not photographs retrieved from the Reader's Digest articles.
Local copies were resized and compressed to JPEG; the browser crops them and
applies warm monochrome, contrast, a print pattern and grain. Processed photo
derivatives retain the license listed below, including ShareAlike where applicable.
These licenses apply to the photographs, independently of the application code.
